# 前后端界面与文案语言规范

为保证毕业设计演示、答辩展示和后续迭代的一致性，项目统一采用中文作为前后端对外展示语言。

## 适用范围

- Web 前端页面
- Web 前端中的按钮、导航、表单标签、状态文案、错误提示、空状态提示
- FastAPI 对外展示的接口文档标题、接口标签、默认响应消息、错误提示
- 项目级说明文档与使用说明

## 执行要求

1. 新增页面默认使用中文标题和中文交互文案。
2. 后端新增接口时，若会被 Swagger/OpenAPI 文档直接展示，应优先提供中文标签与中文提示。
3. 不影响前后端契约稳定性的前提下，默认响应消息与错误提示统一使用中文。
4. JSON 字段名、数据库字段名、内部代码标识可继续保持英文，以降低接口和代码维护成本。
5. 若某一处必须保留英文术语，应优先采用“中文 + 必要英文术语”的表达方式。

## 当前阶段约束

阶段 2 起，登录页、平台导航、设备管理页、区域管理页、平台健康状态页，以及 API 文档中的主要展示信息，均应保持中文化。
